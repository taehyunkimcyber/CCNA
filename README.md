# CCNA Practice Labs

Hands-on Packet Tracer labs for CCNA topics. Each numbered folder is a topic.
Inside each topic folder, individual labs live in `lab-01-*`, `lab-02-*`, and
so on.

Current status: all labs currently in this repository are complete.

## Lab Structure

Use this layout for topics that contain multiple practice labs:

```text
01-example-topic/
├── README.md
├── lab-01-example/
│   ├── README.md
│   ├── images/
│   │   └── topology.png
│   └── packet-tracer/
│       └── lab-01-example.pkt
└── lab-02-extra-practice/
    ├── README.md
    ├── images/
    └── packet-tracer/
```
